## C. Teacher mode: recommendation

One platform, one account system, one backend. A separate teacher workspace (role plus /teach routes) inside Takudzidza. Not a second app, and not mixed into the learner screens.

Why:
- Amayi Learn already has it for primary: schools with staff codes, classes with class codes, scheme of work upload and extraction, term scheme and weekly lesson plan drafts with Word and PDF export, term tests, marks, rule based report comments, assignments, safeguarding records, billing plans. About 5,400 lines in convex/teach, convex/classes, src/grown, src/worksheet. Port as before, with provenance.
- The teacher's value is the link to learners (share a notebook, assign practice, see class weak topics). Split apps lose that. Google ships exactly this in Classroom with NotebookLM and study notebooks with class insights.
- A school licence solves payment and under 18 consent in one move.

Order (each slice shippable, pilot with 3 to 5 teachers before slice 3):
1. Class share, view only, join by code (SPEC 3.6; port amayi classes.ts).
2. Assign a quiz or practice paper; class results by topic, numbers only.
3. Paperwork: scheme of work, lesson plans, school based project guides, term tests with marking schemes; Word and PDF export (port amayi teach/paperwork.ts, plans.ts, termTests.ts, src/office, src/worksheet).
4. Curriculum layer (below).

Gate before any of it: S1, S2, U1, U2 fixed.

## D. Curriculum that updates

It cannot be fully automatic. MoPSE and ZIMSEC publish syllabi as PDFs with no feed or API. Amayi's curriculum map is 8 rows and marked UNVERIFIED in code (convex/teach/curriculum.ts).

Design:
- Syllabus pack = data, versioned: board, subject, level, version, source URL, file hash, effective date; topics and objectives with stable ids (model on 1EdTech CASE).
- Watcher (cron): fetch the known MoPSE and ZIMSEC pages, hash linked files, raise an owner alert on change.
- Draft: model extracts the new PDF into the pack schema and produces a diff against the last version (added, removed, reworded, moved).
- Approve: a named human (Takunda or a paid subject teacher) signs off. Nothing publishes unreviewed.
- Propagate: every scheme, lesson plan, quiz and coverage map stores packVersion and objective ids. On publish, flag affected documents and offer a redraft with a visible diff. Never rewrite a teacher's document silently.
- Institutions: a university or college uploads its own outline as a private pack; same version and diff flow.

Start: Form 1 to 4 Mathematics, Combined Science, Heritage Studies, English (ZIMSEC, Heritage Based Curriculum). Cambridge pack is lower priority given the reported move to ZIMSEC as sole exam board.
