## 1. What Takudzidza is

"Takudzidza" is ChiShona for "we are learning". Product name: **Takudzidza by Taku**. The repo and name stay; a rename may come later, so the name lives in one config constant, never hard coded across screens.

A study platform for anyone from Form 1 upward:

- secondary learners on ZIMSEC O Level and A Level, and Cambridge (IGCSE, AS and A Level);
- university and college students;
- adults studying for professional exams.

Launch market Zimbabwe; built for Southern Africa and international growth (exam boards, languages and currencies are data, not code).

Family: **Amai Learn** (amayi-learn.vercel.app, ECD to Grade 7) hands children over at Form 1. **Takubasa** (takubasa.vercel.app) is the adult work and agents platform. All three share Convex, OpenRouter and the same safety and privacy patterns.

### 1.1 Pivot from the July 2026 design

`docs/PRD.md`, `ARCHITECTURE.md`, `SOURCES.md`, `OVERVIEW.md` and `docs/diagrams/` (14 July 2026) designed an offline first tutor on device models for rural learners, with authored curriculum packs. Kept from July, in this spec:

- **Pedagogy lives in code, language lives in the model** (PRD section 4). In "Guide me" mode the check layer holds the answer; the model never sees it (PRD section 7).
- The evidence base (SOURCES.md, re checked in section 13 below).
- Grade band and level controls (PRD section 9) become the learner's level and exam board on their profile.
- No past paper redistribution (PRD section 18).
- Low end Android and low data as a hard constraint.

Changed: the core is now **the learner's own material** (NotebookLM style notebooks) plus study tools, on a hosted web app (PWA) with offline downloads, not on device models and authored packs. Device inference, the classroom hub and Pangolin hosting are deferred, not deleted. The July docs move to `docs/archive/2026-07/` in Phase 1 with a note pointing here.

## 2. Taku, the tutor

The tutor is named **Taku**, after the founder (Takunda). Decided: the app is tools first; Taku is the one tutor voice inside every tool. Not a mascot, not a companion, no pet, no persona chat, no visible character.

### 2.1 Taku modes (built on Takubasa's agent package format)

Each mode is a package under `modes/<slug>/` with `agent.md` (frontmatter plus instructions), `listing.json` and `tests.json`, parsed by a port of `takubasa/convex/agents/package.ts`. New modes are added like agents. Launch modes:

| Slug | Name in UI | Job |
|---|---|---|
| `summarise` | Summarise | Summary or study guide from selected sources, cited to page |
| `explain` | Explain it simply | Plain explanation at the learner's level, cited |
| `quiz` | Quiz me | Quiz or mock exam at a chosen difficulty, with a marking key |
| `flashcards` | Flashcards | Cards from sources, fed to spaced repetition |
| `exam-coach` | Exam coach | Syllabus aligned practice; marks answers against a key |
| `essay` | Essay feedback | Feedback on a draft; never rewrites assessed work |
| `audio` | Audio overview | Spoken overview script, then text to speech |
| `planner` | Study planner | Plan from exam date, subjects and hours per week |

Package frontmatter additions over Takubasa: `guide: supported | none` (whether the mode has a Guide me variant), `outputs: [text|cards|quiz|mindmap|audio|plan]`, `citations: required | optional`.

### 2.2 Show me the answer, or Guide me

Evidence: Bastani et al., PNAS 122(26), 2025, about 1,000 high school maths students. Unrestricted GPT 4 ("GPT Base") raised practice scores 48% but students scored 17% lower than the control group once access was removed; a guardrailed hint giving version ("GPT Tutor") largely mitigated that harm. Use "largely mitigated", not "did no harm". Sources in section 13.

Decided (D1b): **the learner chooses, with a toggle.** Takunda does not want to force a teaching style on anyone.

1. Default: **"Show me the answer"**. Taku gives the answer with full working, step by step.
2. Toggle **"Guide me"** (per notebook, remembered, visible on every answer screen): Taku coaches with a hint ladder (nudge, guiding question, worked example of a *similar* problem) and only reveals the answer when the learner asks or gets it right. The toggle is prominent because the evidence favours guiding, but it is never forced.
3. Essay mode never writes a finished essay for submission in either setting; it gives feedback, structure and questions.
4. In "Guide me", maths answers are held by the maths check layer (section 3.5) outside the model context, and an output filter blocks a reply that contains the held answer (numeric and equivalent forms).
5. A red team script (port of `amayi-learn/scripts/kids-redteam.mjs`) attacks answer leakage in Guide me mode and safety before every release.

## 3. Core product

### 3.1 Dashboard first
- Goals: exam board, level, exam date per subject, subjects, hours per week.
- Study plan generated by the planner mode, editable, rebalanced weekly.
- Progress **without streaks**: time studied this week against plan, cards due, quiz scores by topic. No streak counters, no loss framing, no badges for daily use.
- Weak topics: from quiz and flashcard results, tagged by syllabus topic where a syllabus is known.

### 3.2 Notebooks (NotebookLM pattern)
- Sources: PDF, Word (.docx), phone photos of notes and textbook pages, pasted text, web links (fetched server side, text only, link kept).
- Every answer is **cited to source and page**; tapping a citation opens the page text with the quote highlighted.
- **Source mode toggle**: "Only my material" or "My material plus Taku's ideas". In the second mode every addition is visibly marked as Taku's.
- Reuse: `amayi-learn/convex/sources/*` (docx reader without a library, PDF page count, upload limits and cost estimate, source modes, origin settling and stripping). Amai Learn's citation check (`settleOrigin`) accepts an item only if its `fromPage` is one of the topic's pages. **Takudzidza tightens this**: each citation carries a short quote, and the server verifies the quote appears (normalised) on the cited page; otherwise the claim is dropped (only mine) or marked as Taku's (mine plus).
- Amai Learn's extraction schema is shaped for teacher scheme rows (grade, term, week, topic). Generalise to pages and chunks: `sources -> pages -> chunks` with embeddings for retrieval (decision D8 on the embedding route).

### 3.3 Study outputs
- Summaries and study guides.
- Flashcards with spaced repetition and two buttons, "Got it" and "Try again". Scheduler: FSRS (open source, published parameters) or SM 2 as fallback; decide in Phase 3 by test, default FSRS.
- Quizzes and mock exams at chosen difficulty with marking keys and mark allocation. Tests must not read as AI written and must look like a real exam board paper (D10): numbered questions, marks in brackets, separate marking scheme, clean print layout, no dashes. Start from `amayi-learn/convex/ai/prompts/kids-term-test.md` and `convex/teach/termTest*.ts`, plus `takubasa/agents/taku-humaniser` rules.
- Mind maps (rendered from structured output, no image generation).
- Audio overviews and read aloud: reuse `amayi-learn/convex/kids/speech.ts` (sentence split, chunked speech calls) and the router's `speech` action.
- Print packs: reuse `amayi-learn/src/worksheet/*` (@react-pdf/renderer).

### 3.4 Exam focus
- **Any course or exam works** (ZIMSEC, Cambridge, ACCA, CTA, university modules, anything): Taku works from whatever the learner uploads. Syllabus packs are an extra layer, not a gate.
- First syllabus packs (topic lists and exam formats, so Taku can show coverage gaps): ZIMSEC O Level and A Level, Cambridge IGCSE and AS and A Level. Professional bodies (ACCA first) follow.
- Syllabus aligned practice for loaded packs using public syllabus topic lists (ZIMSEC syllabi are public; source in July SOURCES.md).
- Past paper practice **only from papers the learner uploads**, kept private to that learner. Never redistribute papers or marking schemes, never share uploaded papers via class sharing (Cambridge copyright policy, July SOURCES.md).

### 3.5 Checking layers (maths and accuracy)
Decided (D6): no Python service. Large hosted models do the tutoring; deterministic checks run underneath so wrong answers are caught before a learner sees them. Nothing claims 100%; when a check fails Taku regenerates or says plainly it is not sure.

1. **Maths check**: a JS CAS (candidates: mathjs, nerdamer; pick by golden tests in Phase 5) verifies final answers and each algebraic step. Runs in Convex actions and in the browser. Golden test cases come from `taku-dzidza-local/scripts/tools/solve_math.py` (SymPy; solve, factor, simplify, expand, domain restrictions) and its tests.
2. **Number check**: every number in a reply must appear in the sources, the user's messages or a CAS result. Port `takubasa/convex/ai/verify.ts` and `convex/runtime/grounding.ts`.
3. **Source check**: every cited claim carries a quote verified on the cited page (section 3.2).
4. **Second opinion**: marking keys, mock exam answers and syllabus claims are checked by a second model (judge brain) before display.

### 3.5b Artifacts (interactive visuals)
Decided: yes, in two steps.
1. A **built in widget library** Taku fills with structured data: function grapher, geometry board, physics and chemistry simulations, timelines, flowcharts, mind maps, tables. Fast, offline, low data, safe for under 18s. (Phase 6.)
2. Later, **free form artifacts** Taku writes on the fly, rendered in a sandboxed iframe (no network, no storage, strict CSP). (Phase 8+.)
These are diagrams and interactive tools, not generated photos.

### 3.6 Sharing
- A teacher or lecturer shares a notebook with a class as **view only** (sources, outputs, no learner data). Class join by code; reuse `amayi-learn/convex/classes/classes.ts` patterns.
- Study groups: later (Phase 6+).

### 3.7 Languages and access
- English first; ChiShona UI strings and Taku able to explain in ChiShona (Amai Learn already ships English and ChiShona strings, `src/kids/i18n.ts`).
- Offline: download a notebook (pages, outputs, cards) and its audio; reuse `amayi-learn/src/offline/*` and vite-plugin-pwa.
- Low data mode: no images except essentials, compressed text, audio on demand only.
- Cheap Android: performance budget set in Phase 1 (bundle size and first load targets measured, not guessed).

### 3.8 Safety and privacy
- Under 18s need guardian consent before a profile exists. Cyber and Data Protection Act [Chapter 12:07]: a child is under 18 and processing a child's data needs a parent or guardian's consent with reasonable verification (section 26 per DLA Piper's summary; verify against the gazetted text before launch). Reuse `amayi-learn` consent records and `takubasa/convex/learners/consentRecord.ts` (downloadable record).
- Safety layers from Amai Learn: deterministic prefilter (`convex/kids/prefilter.ts`, retuned for teens and adults: school topics like sex education, history of violence and drugs in biology must pass), model input and output checks failing closed (`convex/kids/safety.ts`).
- Distress: under 18s see **Childline Zimbabwe 116** (free from all Zimbabwe networks; WhatsApp numbers to be re confirmed on childline.org.zw). Adults see an adult helpline (to be confirmed, decision D11).
- No companion behaviour (no "I miss you", no affection, no persona chat), no ads, learner data never trains models, zero data retention routes only (router sends `data_collection: "deny"` and `zdr: true`, as Amai Learn does).
- Account delete and retention sweeps: port `amayi-learn/convex/accounts/deletion.ts` and `convex/privacy/retention.ts`.
- Ordinary chats: stored only inside the learner's notebook (they own it); flagged safety messages kept 30 days as in Amai Learn.

### 3.9 Business
- Free tier, student plan paid by EcoCash, school and university licences, telecom zero rating talks.
- Price proposal (decision D2) is in section 9 with its evidence. No billing code until D2 is signed.

### 3.10 Study styles and personalisation
- At sign up the learner gives a birth year (needed for consent anyway) and may take an **optional 3 or 4 tap quiz** ("How do you like to study?"); skipping gives the age based default. Changeable any time in Settings.
- Styles (decided names):

| Style | For | Feel |
|---|---|---|
| **Locked In** | anyone who wants focus; default for professional exams | All business, no faff: plain screens, dense summaries, exam board tone, no slang |
| **Cook Mode** | teens who want energy ("cooked") | Vibrant: louder use of Honey and Butter, more visual cards, short punchy copy, light lingo ("lock in"), more Scroll and quick quizzes |
| **Calm** | default for most adults | Subtle and quiet, like NotebookLM |

- A style changes Taku's tone, colour intensity (same tokens), density, imagery set and which tools are surfaced. Facts, checks and safety are identical in every style.
- **Accessibility mode** (separate from style, combinable): dyslexia friendly spacing and line length, larger text, read aloud with sentence highlighting (Amai Learn `speech.ts` already splits sentences), shorter chunks for slow readers, high contrast, reduced motion. Offered in the quiz ("Is anything hard for you, like reading fast?") and in Settings.
- **Learns from feedback**: thumbs up or down and quick "too long / too hard / too easy" chips adjust the learner's settings. Product improvement uses aggregated, consented analytics only; **learner content never trains models** (section 3.8). Under 18s: minimal analytics, no content.

### 3.11 Scroll, hooks and media formats
| Format | What | Plan |
|---|---|---|
| **Scroll** (the doom scroll feed for notes) | Full screen vertical cards from the learner's notebook: cited fact, tap to reveal question, swipe true or false, crop of a diagram from their own pages, 20 second Taku audio clip. Sets of about 20 with an end screen; no endless autoplay. Answers feed flashcard review and weak topics | Free |
| **Hooks** | Marketing style openers and cliffhangers ("Most people get this wrong..." then the answer on the next card) in Scroll, summaries and reels | Free |
| **Reels** | Animated text, the learner's diagrams and a voice, rendered on the phone (no video streaming, small download) | Paid |
| **Podcast** | Two voice discussion of the notebook, like NotebookLM audio overviews | Paid |
| **Story mode** | Notes retold as a story, read or listened to, with a quick quiz after; every fact still cited | Paid |
| **AI comics and AI video stories** | Needs image or video generation, an exception to the no generated images rule, and accuracy checks on visuals | Later; Takunda decides |

### 3.12 Study music (later)
- Preset study music by mood or genre (for example deep house, lo fi, piano), generated royalty free with music models. Amai Learn's router already has a `music` action (Lyria via OpenRouter) to reuse. Check each model's commercial use terms before shipping.
- Learners can build and share playlists of app music. Recommending outside songs only as links (Spotify or YouTube), never hosted.
- Low data: downloads on WiFi only by default. Instrumental by default (lyrics tend to compete with reading).

### 3.13 Get help
- A **Get help** section always one tap away in the main menu: Childline 116 for under 18s; verified adult and emergency numbers by country (only numbers verified from an official source; none are listed until verified).
- Distress detected by the safety layers opens Get help straight away.

## 4. Design

- Base: warm cream and butter, black pill buttons, large rounded cards, generous spacing.
- Type: **Lexend** (Google Fonts, OFL; designed for reading proficiency) for display and body; JetBrains Mono only for maths input. Self host via @fontsource to work offline.
- Palette (decision D5), checked against Amai Learn's tokens (`amayi-learn/src/index.css`): Amai cream `#fff6e6`, gold `#f4ba57`, coral deep `#b4512c`, leaf deep `#3f6431`. The proposed colours sit next to each, so the family reads as related.

| Token | Hex | Use |
|---|---|---|
| Cream | `#FFF8EC` | page background |
| Butter | `#F8E2A8` | cards, selected states |
| Honey | `#F2B33D` | fills and accents only, **never text** |
| Ink | `#111111` | text, pill buttons |
| Ink Soft (new) | `#5C5346` | secondary text |

| Text on | Cream | Butter | Honey |

Cream text on Ink 17.89, on Msasa 5.19, on Sage 5.58: all pass. Rules: Msasa Red body text never on Butter; nothing but Ink on Honey; Honey never as text. A unit test asserts every token pair used in CSS (port `amayi-learn/tests/kids/style.test.ts`).

## 5. Architecture

Same stack as Amai Learn and Takubasa so code moves byte for byte:

- Vite, React 19, React Router 7, TypeScript, vite-plugin-pwa (PWA, installable on Android).
- Convex (database, functions, file storage, crons) with Convex Auth (password, Google later).
- AI: one router file (port `amayi-learn/convex/ai/router.ts`), the only file that knows OpenRouter. Mock mode returns recorded fixtures or throws `MissingFixtureError`; never a default. Structured output routing to schema enforcing providers. Purposes: `source_read`, `chris_answer`, `chris_tool`, `input_check`, `output_check`, `speech`, `embed`.
- Budgets and usage: port `takubasa/convex/ai/budget.ts` (per user daily token budget, monthly spend cap that drops to the fast tier) and `convex/usage.ts`.
- Brains: port `takubasa/convex/ai/brains.ts` naming pattern and owner decisions; the brains console and admin console come in Phase 7. Model ids are chosen in Phase 1 by checking the OpenRouter models and ZDR endpoint list on that day, not from this document.
- Jev decision scoring (`takubasa/convex/decisions/jev.ts`): optional, `JEV_MODE=off` by default; candidate use is classifying work type (studying or assessed).
- Image brains and Studio: **not used** (no image generation in Takudzidza).
- Hosting: Vercel (web), Convex cloud. Env vars from Takunda: `CONVEX_DEPLOY_KEY`, Vercel project, `OPENROUTER_API_KEY`. Until they exist everything runs in mock mode.

Data model (first cut): `users`, `profiles` (level, board, subjects, exam dates, language, work type default, birth year), `consents`, `notebooks`, `sources`, `pages`, `chunks`, `outputs` (summary, guide, quiz, cards, mindmap, audio), `cards` (FSRS state), `attempts`, `plans`, `classes`, `classShares`, `safetyFlags`, `aiUsageDaily`, `auditLog`.
